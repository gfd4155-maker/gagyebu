# 가계부 앱 — 디자인 의뢰용 현황 요약

## 1. 무엇을 만드는 서비스인가
개인용 가계부 웹앱. 수입/지출을 기록하고, 월별로 소비 흐름·예산·고정비 대비 변동비 등을 확인하는 용도.

## 2. 기술 스택
- **프레임워크**: Next.js 16 (App Router), React 19, TypeScript
- **스타일링**: Tailwind CSS v4 (현재는 기본 유틸리티 클래스로만 작업된 상태 — 커스텀 디자인 시스템 없음)
- **데이터베이스**: Supabase (Postgres) — 거래 내역은 실시간으로 DB에 저장/조회/삭제됨
- **인증**: 없음 (아직 로그인 기능 없이 누구나 읽고 쓸 수 있는 상태 — 프로토타입 단계)
- **반응형**: 모바일 우선 레이아웃 (`max-w-3xl` 중앙 정렬 카드형 UI)

## 4. 현재 디자인 상태 (있는 그대로)
- 색상: 배경 `#f4f5f7`(연회색), 카드 흰색 + 옅은 그림자, 강조색은 파랑(수입)/빨강(지출)/남색(주요 버튼) — Tailwind 기본 팔레트 그대로 사용
- 카드 기반 UI, 라운드 모서리(`rounded-2xl`), 그림자(`shadow-sm`) 정도만 적용
- 아이콘·일러스트·브랜딩 요소 전혀 없음, 순수 기능 위주의 "와이어프레임에 가까운" 상태
- 폰트는 Geist(Next.js 기본) 그대로
- 다크모드 없음

## 5. 데이터 모델 (참고용)

```
budget 테이블
- id, date, type(수입/지출), category(카테고리), amount(금액)
- memo(메모), cost_type(고정비/변동비, 지출만 해당), created_at
```

카테고리는 수입 5종(급여/부수입/임대수입/용돈/기타), 지출 11종(식비/카페·간식/교통/쇼핑/주거/통신/보험/건강/여가/구독/기타)으로 고정.

## 6. 디자이너에게 요청할 만한 것
- 전체 룩앤필(컬러 팔레트, 타이포그래피, 카드 스타일) 리브랜딩
- 입력 폼 UX 개선 (현재는 단순 텍스트/셀렉트 나열)
- 카테고리별 색상·아이콘 시스템 (11개 지출 카테고리를 시각적으로 구분)
- Summary 탭의 데이터 시각화(차트) 톤앤매너
- 모바일/데스크톱 반응형 레이아웃 방향성
